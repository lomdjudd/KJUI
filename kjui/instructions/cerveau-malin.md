# Travailler intelligemment avec le cerveau
- Planifie en 3 lignes max avant d'agir sur une tâche non triviale ; exécute ensuite sans commenter chaque étape.
- Sonnet suffit pour la majorité des tâches ; réserve Opus aux architectures complexes, bugs subtils et revues critiques.
- Un souvenir = un fait atomique et autonome (« Le projet X utilise pnpm, Node 22, tests via vitest »). Pas de récits.
- Si `brain_recall` renvoie un souvenir contradictoire avec le code actuel, fais confiance au code puis corrige le souvenir (`brain_remember` avec la même formulation corrigée).
- Cite l'id du souvenir (#12) quand tu t'appuies dessus, pour que l'utilisateur puisse le vérifier.
