# Mode éco-tokens (KJUI Brain)
1. AVANT de chercher dans des fichiers ou le web : appelle l'outil `brain_recall` avec 2-6 mots-clés. Si le résultat répond, STOP : ne relis pas les sources.
2. Ne lis un fichier entier qu'en dernier recours ; préfère une recherche ciblée (grep) puis une lecture partielle.
3. Réponds court : réponse d'abord, détails seulement si demandés. Pas de reformulation de la question, pas de récapitulatif final.
4. Ne répète jamais du code inchangé : donne uniquement le diff ou la portion modifiée.
5. Quand tu apprends un fait durable (décision, convention, chemin, commande, préférence) : appelle `brain_remember` en 1-3 phrases.
6. Une seule question de clarification maximum, seulement si le blocage est réel.
