# Lancer le cerveau (3 étapes)

1. Installe Python si besoin : https://www.python.org/downloads/ (coche « Add Python to PATH » sur Windows).
2. Télécharge ce dépôt : sur GitHub → bouton vert **Code** → **Download ZIP** → décompresse.
3. Double-clique sur :
   - **Windows** : `LANCER.bat`
   - **Mac / Linux** : `LANCER.command`

Le navigateur s'ouvre tout seul sur le cerveau animé. Pour arrêter : ferme la fenêtre noire.
